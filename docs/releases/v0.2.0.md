Droid Webcam 0.2.0 is an initial preview for using an Android phone as a local Wi-Fi webcam on Windows 11 and Ubuntu.

- Choose a front or rear camera, 480p/720p/1080p, a target of 15/30/60 FPS, and Economy/Balanced/High image quality. Available combinations depend on the phone.
- Default to 720p/30 with Balanced quality. Android shows the rate acknowledged by the host.
- Pair locally with a single-use invitation and pinned TLS 1.3.
- Use a Rust Media Foundation source on Windows or a V4L2 loopback device on Ubuntu.

## Downloads

- `DroidWebcam-0.2.0-windows-x86_64.zip` contains the Windows EXE with its embedded camera-source DLL and instructions. Requires Windows 11 x64. Extract it and run `.\DroidWebcam.exe install-source` once from elevated PowerShell. Start the host in regular PowerShell with `.\DroidWebcam.exe serve <LAN-IPv4>:47470 --camera`.
- `DroidWebcam-0.2.0-ubuntu-x86_64.tar.gz` contains the Linux host and virtual-device setup script. Extract it, follow the README to install `v4l2loopback` and create `/dev/video10`, then run `./dist/droid-webcam serve <LAN-IPv4>:47470 --camera --device /dev/video10`.
- `DroidWebcam-0.2.0-android-debug.apk` is a debug-signed Android 10+ APK. Install it, choose settings, paste the host invitation, and tap Start. Each Actions build generates a fresh debug signing key, so an APK signed by an earlier build must be uninstalled before installing this one.
- `SHA256SUMS.txt` contains checksums for the three downloads.

GitHub Actions builds all downloads from the release source commit. Publication runs after the builds, Rust tests, and Java/Rust TLS loopback checks succeed. The Windows EXE is built natively with MSVC. Full setup, removal, and device-acceptance instructions are in the [README](https://github.com/siarheisinelnikau/droid-webcam/blob/v0.2.0/README.md).

Physical Android capture, Windows camera discovery in applications, and Ubuntu video output through a loaded v4l2loopback device still require testing on devices. The Windows binary is unsigned, and the APK uses a debug signing key. Actual FPS depends on the phone, selected quality, host, and network.
